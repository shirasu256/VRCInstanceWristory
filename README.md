# VRC Instance Wristory

VRChatでプレイ中に訪問したインスタンスのIDを、左手首（設定で右手首にもできます）の甲側にSteamVRオーバーレイとして古い順に表示します。
同じ表示をデスクトップのウィンドウにも出し、そこから行の詳しい情報や撮った写真を見たり、そのインスタンスのページを開いたり、設定を変えたりできます。

![手首のパネル](docs/ui/render-sample-history.png)

> VRChat 公式のアプリではありません。VRChat Inc. とは関係ありません。

## 使い方（はじめての方へ）

### 必要なもの

| 項目 | 内容 |
| --- | --- |
| PC | Windows 11（64ビット）。Windows 10 では確かめていません |
| VR | SteamVR |
| VRChat | PC版（SteamVR 経由で遊んでいること） |

ほかにインストールするもの（.NET など）はありません。

### 導入

1. [Releases](../../releases/latest) のページから、**`VRCInstanceWristoryApp-win-Setup.exe`** をダウンロードします
   （「Source code」と書かれたファイルはプログラムの元のコードなので、使いません）。
2. ダウンロードした `VRCInstanceWristoryApp-win-Setup.exe` をダブルクリックします。
3. 「Windows によって PC が保護されました」と出たときは、「詳細情報」を押してから「実行」を押します。
   このアプリには、配布元を証明する電子署名（有料）を付けていないため、初めて開くときにこの画面が出ます。
4. インストールが終わると、アプリが起動します。デスクトップとスタートメニューにも「VRC Instance Wristory」ができます。
5. 初めて起動すると使い方の案内が出ます。「わかった」のあとの初期設定の画面で、履歴を残す時間や自動起動を選べます（あとから変えられます）。

管理者の権限は要りません（いまの Windows のユーザーにだけインストールします）。インストール先は `%LocalAppData%\VRCInstanceWristoryApp` です。

VRChat のメインメニュー（「ワールド」などのタブ）を開くと、左手首に訪問したインスタンスの一覧が出ます。
SteamVR を先に起動しておく必要はありません（あとから SteamVR を起動すると、自分からつなぎます）。

### 新しい版に更新する

新しい版が出ると、ウィンドウの左下の段の右端に **「アプリを更新」** と出ます（起動して30秒後と、その後12時間ごとに確かめます）。手首のパネルの下部と SteamVR のダッシュボードにも「新バージョンが公開されています」と出ます。
押すと確かめる画面が出るので「はい」を選ぶと、ダウンロードが終わったところでアプリが一度終了し、新しい版で起動し直します。
設定と訪問履歴はそのまま引き継ぎます。

- ウィンドウの「一般設定」の一番下の「アップデート」でも、現在のバージョンの確認・「今すぐ確認」・「更新して再起動」ができます。
- 自動で確かめたくないときは、「アップデートを自動確認する」をオフにします（「今すぐ確認」では確かめます）。
- 勝手に更新して起動し直すことはありません。VR の最中に押したときは、手首のパネルも一度消えて、起動し直すと戻ります。

### アンインストール

Windows の「設定」→「アプリ」→「インストールされているアプリ」で「VRC Instance Wristory」を選び、「アンインストール」を押します。

- 「Windows のログオン時に起動する」の登録は、アンインストールのときに外します。
- 「SteamVR の開始時に自動起動する」の登録は、**SteamVR が起動していれば**外します（SteamVR への登録は、SteamVR にしか外せないため）。
  SteamVR が起動していないときに使っていた場合は、SteamVR の設定の「起動時に開始するオーバーレイ」で残った項目をオフにしてください（残っていても、何も起動しません）。
- **設定と訪問履歴（`%LocalAppData%\VRCInstanceWristory`）は消しません。** 入れ直したときに、そのまま引き継げます。
  すっかり消したいときは、アンインストールのあとでこのフォルダーを削除してください（エクスプローラーのアドレス欄にそのまま貼り付けると開けます）。

### 読み取るもの・送るもの

- 訪問の記録は、**この PC にある VRChat のログ**（`%UserProfile%\AppData\LocalLow\VRChat\VRChat`）から読み取ります。VRChat の API は使わず、どこへも送りません。
- 新しい版を確かめるときに、GitHub（このリポジトリの Releases）へ問い合わせます。送るのはふつうの Web の問い合わせだけで、記録の中身は送りません。
- 「AFK を検知する」をオンにしたときだけ、VRChat と OSC でやりとりするため、この PC の中とローカルのネットワークで通信します（Windows のファイアウォールの許可を求められます）。
- 行のボタンでインスタンスやグループのページを開くと、既定のブラウザで vrchat.com を開きます。

### うまく動かないとき

- ウィンドウの左下の段に、いまの状態と、うまく動かない理由が出ます。値を指すと、原因と対処が出ます。
- 不具合を知らせるときは、`%LocalAppData%\VRCInstanceWristory\app.log` を添えてください。
  このファイルには訪問したインスタンスの ID などが含まれることがあるので、送る前に中身を確かめてください。

## 機能

- **デスクトップにもウィンドウを出します。** 左に手首のパネルと同じ表示（同じ描画を縮小したもの）、右にタブで分けた中身、左下に動作の状態が並びます。
  パネルはマウスで操作でき、ホイールでスクロール、**行のクリックでその行を選んで「選んだ行」のタブに詳しい情報を出し**、
  **行の右クリックで目印と「ブラウザで開く」のポップアップ**（VR内でトリガーを引いたときと同じもの）、見出しの「延長」のクリックで延長、
  **「リセット」のクリックで確認のあと訪問履歴を今すぐ消せます**（VR内と同じ）。
  スクロール位置はVR内とは別です。行が少なくてもパネルの枠はウィンドウの下まで描き、行は上に寄せます。
  パネルは等倍より大きくしないので、それより横に広げたぶんは右側（タブと中身）が広がって埋めます。
  左下の状態の段の右端には「開発: shirasu256」（押すと https://5rs.uk/0 を開く）と「実装: Claude Code by Anthropic」を出します。
  右側のタブは次の3つです。

  | タブ | 中身 |
  | --- | --- |
  | インスタンス詳細 | 見出しにインスタンス番号・「滞在中」・ワールド名・インスタンスタイプ、「ブラウザで開く」（設定によっては「ここへ戻る」）とブックマークアイコン（目印）の3つのボタン、グループ名（「グループ名:」の欄を押すとその場で打ち込める）と完全な Group ID（押すとそのグループのページを開く）、**撮った写真のサムネイル**（ダブルクリックでその写真を既定のアプリで開く）と「フォルダーを開く」、このインスタンスにいたユーザーの名前（押すとそのユーザーのページを開く。入り切らない分は右下に右寄せで「ほか n人」）。選んでいる行をもう一度押すと、選んでいない状態に戻ります |
  | VRオーバーレイ設定 | **VR オーバーレイ機能を有効にする**（既定はオン。オフにすると手首のパネルを出さず、このタブの設定はすべてグレーアウト）。手首パネル：パネル位置（左手首／右手首）・**手首パネルの移動を有効にする**（既定はオン。オフにするとグリップを握ってもパネルは動かない）・ロード画面中もパネルを表示する・パネルの幅・背景の不透明度（50〜100%。90%からは2%刻み）・非表示にする角度（2°刻み）・フェードアウト時間・スクロールの速さ・**トリガーで操作メニューを表示**（既定はオン。オフにすると、行を指してトリガーを引いても目印と「ブラウザで開く」のメニューを出さない）・「手首パネルの位置をデフォルトに戻す」ボタン（パネルの位置と角度だけを既定へ戻す。ほかの値は変えない）・「手首パネルのパラメータをデフォルトに戻す」ボタン（位置と角度・付ける手首以外の手首パネルの値を既定へ戻す）・**コントローラーの振動を有効にする**（既定はオフ。オンにすると、手首のパネルで指す部品が変わったとき・トリガーで押したとき・掴んだときに、操作する手のコントローラーが短く振動）。履歴自動リセットの予告通知（指定した表示タイミングになった時、VRChatのマイクアイコンそばに通知を表示）：**リセット予告アイコンを表示する**（既定はオフ。オフにするとこのまとまりのほかの設定はグレーアウト）・表示位置（‹ › でマイクのアイコンの左下→左→左上→上→右上→右→右下→下と巡る。既定は左下）・マイクアイコン位置（横・縦は0.5cm刻み、奥行きは5cm刻み。アイコンがマイクのアイコンとずれるときに合わせる）・表示サイズ（60〜140%の5段階）・不透明度（50〜100%。既定100%）・点滅回数（1／3／5／10／30回）・表示タイミング（1／3／5分前。既定3分前）・**AFKから復帰時に再表示する**（既定はオン） |
  | 一般設定 | 履歴：**履歴の自動リセットを有効にする**（既定はオン。オフにすると手で「リセット」するまで履歴を残し（再起動しても消えない。最新の500件・30日以内まで）、パネルの見出しは日付付きの時刻と「履歴の自動リセットが無効化されています」になる）、**リセットまでの時間**（5〜900分。60分未満は5分、60分から10分、120分から30分、300分から60分刻み。既定60分。「延長」もこの時間だけ延ばします）、**滞在中はカウントダウンを停止する**（既定はオン）、**AFK中はカウントダウンを停止する**（既定はオフ）、**直前のリセットを戻す**（いちばん最近のリセット――「履歴リセット」・外部からのコマンド・自動リセットのどれか――で消えた行と目印を1回だけ戻す。戻した時点から数え直す。アプリを終了すると戻せなくなる）、訪問履歴に含めるインスタンスタイプ（Public / Group Public / Group+ / Group / Friends+ / Friends / Invite+ / Invite から選ぶ。既定は Public / Group Public / Group+ / Group。Group はログ上の Group Only。変えるとログを読み直して一覧を作り直します）、インスタンス操作の挙動（ブラウザでインスタンスリンクを開く／VRChat クライアントを再起動して join）、グループ名：グループ名設定済みのグループも Group ID を表示する・**グループ名のインポート／エクスポート**（JSON。インポートはダウンロードフォルダーから選ぶ）、写真を開くアプリ（既定／アプリを選択）、SteamVR の開始時に自動起動する・Windows のログオン時に起動する、デスクトップウィンドウを常に手前に表示する、外部連携、アップデート（現在のバージョン・アップデートを自動確認する・今すぐ確認・更新して再起動。インストーラーで入れた版だけ）（この順に並ぶ） |

  設定は**変えたその場で反映して `settings.json` へ保存します**（再起動は不要です。起動の2つだけは、設定ファイルではなくSteamVRとWindowsの登録を変えます）。
  右側の設定が入り切らないとき（既定の大きさの「一般設定」など）は、設定の上でホイールを回すと送れます（送れる間は −／＋ の行の上でも送ります。値はボタンで変えます）。
  リセットまでの時間と記録する種類は、最後に押してから0.8秒たってから反映します（−を押し続けて短い値を通り過ぎただけで履歴が消えないように）。
  短くして期限を過ぎた履歴はその場で消え、長くしても（再起動しても）戻りません。記録しない種類の訪問も回数だけは数えているので、あとから記録に加えた種類の過去の訪問にも回数が付きます。
  **SteamVRにつながらなくてもウィンドウだけで動き続け**、つながっていない間にSteamVRが起動したら自分からつなぎます。SteamVRを終了してもウィンドウは残ります。
  左下には VRChat・VRChat ログ・SteamVR・手首パネルの状態が出ます（「正常動作中」「正常追跡中」「動作中・接続エラー (D3D11デバイス枯渇)」「非表示・メインメニュー非表示」など）。
  点の色は、アクセント色＝正常、薄いアクセント色＝正常で、いまはパネルを出す場面ではないだけ、灰色＝動いていない・待っている、黄＝一部が働かない・すぐに戻る見込み、赤＝手を打つ必要がある、です。赤は1秒周期で点滅し、黄は5秒周期でゆっくり明暗します。
  **値を指すと、その上に詳しい文（原因と対処）が出ます**（値が切れて末尾が薄くなっているときは全文も）。出しうる値と詳しい文の一覧は [docs/status-messages.csv](docs/status-messages.csv) にあります。
  **最小化するとタスクトレイに入ります**（ダブルクリックで戻る。右クリックで「ウィンドウを開く」「VRC Instance Wristory を終了」）。初回起動の案内と初期設定の画面の間は、最小化してもタスクバーに残ります。
  アイコンはSteamVRのダッシュボードと同じ図です。
  ウィンドウを閉じるとアプリが終了します。出したくないときは `--no-window` を付けるか、設定で `showDesktopWindow` を `false` にします。
- **初めて起動したときは、ウィンドウに使い方の案内を出します。** VRモードではVRChatのメインメニューを開いている間だけ手首にパネルが出ることを、イラストで説明します。
  「わかった」を押すと**初期設定の画面**に進み、リセットまでの時間・訪問履歴に含めるインスタンスタイプ・起動・パネル位置・「VRChatのAFKを検知する」をその場で設定できます。
  「はじめる」を押すとふだんの画面になり、次からは出しません（もう一度見たいときは、`settings.json` の `welcomeCompleted` を `false` にしてから起動します）。
- **VRChat の AFK の検知は、既定ではオフです。** 「AFK中はカウントダウンを停止する」か「AFKから復帰時に再表示する」をオンにすると（初期設定の画面の「VRChatのAFKを検知する」でも。こちらは2つの設定も一緒にオンにします）、
  VRChat の OSC で AFK の状態を受け取り始め、その場で Windows のファイアウォールの許可を求められます（VRChat に受け口を知らせる mDNS がネットワークを使うため）。
  2つともオフにすると受け取るのをやめます。
  許可を求める画面で「許可しない」を選んだあとは、Windows がその選択を覚えているので画面はもう出ません。
  そのときは、オンにしようとすると**ファイアウォールでブロックされていることと直し方を知らせ、設定はオフに戻します**。
- **同じ設定を、SteamVRのダッシュボード（コントローラーのシステムボタンで出る画面）でも変えられます。**
  下のバーの「VRC Instance Wristory」のアイコンを選ぶと、ウィンドウの「パネルと行の操作」「記録と起動」と同じ設定（ウィンドウだけの「写真を開くアプリ」「常に手前に表示」「起動」「外部連携」を除く）が2列で出て、レーザーで操作できます。
  字やボタンはダッシュボードの枠に対して控えめな大きさ（2026-09-27に70%へ縮小）で描きます。ただし「リセットまでの時間」と「訪問履歴に含めるインスタンスタイプ」の選択肢は、「リセットまでの時間」が1行に収まる最大の大きさ（いまは約1.65倍）で描きます。ダッシュボードの枠の中では、設定の画面全体を面積で75%の大きさに出します（周りは透明）。どちらで変えても、もう一方の画面にもすぐ反映されます。グループ名の打ち込みとインポート／エクスポートはウィンドウだけです。
- 記録する対象は、既定では **Public / Group Public / Group+ / Group Only** の4種類だけです（Friends・Friends+・Invite・Invite+ は記録しません）。ウィンドウで変えられます。
- パネルを出すのは **メインメニューの「ワールド」「Live Now」「ソーシャル」「VRChat Plus」タブを開いたとき**（ログの `OnPageAboutToShow`）です。
  閉じるのは **コントローラーの B / Y ボタンを短く押したとき**（押してから **0.1秒以内に離したとき**）です。
  VRChatのメインメニューは B / Y を長押ししても閉じないので、こちらも**長押しでは閉じません**。
  片方を押し続けたまま、もう片方を短く押したときも（VRChatと同じく）閉じます。
  加えて、**VRChatのログにメインメニューを閉じた記録が出たときも閉じます**。B / Y の押し方によらず、メインメニューが閉じればパネルも閉じます（ログを読む分、最大0.25秒ほど遅れることがあります）。
- **インスタンスの移動中（ロード画面）は、メインメニューを開いているのと同じ扱いです**（設定「ロード画面中もパネルを表示」。既定はオン）。
  退出した時点で出て、閉じていても出ます。ロード画面が終わって**世界が見えたあと**（ログの `Finished entering world.`）、
  **初めて手首を寝かせて（パネル正面から30度以上ずれた向きになって）見えなくなった時点で閉じます**。
  そのときメインメニューが開いているかどうかは問いません。閉じたあとは、もう一度メインメニューを開けば出ます。
  この設定（`showPanelDuringLoading`）をオフにすると、移動を始めた時点で閉じ、ロード画面の間は出しません。
- さらに、**パネル正面から上下左右いずれかが30度以上ずれた向き**からは見えません。手首を返して正面から見たときだけ出ます。
- 対象インスタンスに滞在している間は履歴を消しません。**離れてから60分**（ウィンドウで変えられます。以下の60分はすべてこの時間）でまとめて消えます。見出しの右に**「履歴リセットまで: 59:42」**のように消えるまでの残り時間を出し（リセットまでの時間を100分以上にしているときは `1:39:59`・`0:59:59` のように、減っても時・分・秒で出します）、滞在している間は **「カウントダウン停止中: 60:00」** になって止まります（その間は「延長」が薄くなり押せません）。その右の**「延長」ボタンを右手で指してトリガーを引くと、残り時間が `60:00` に戻ります**（押した時点から60分を数え直します。何度押しても、最後に押した時点から60分は消えません。延長はアプリを再起動しても失われません）。見出しの右端の赤い**「履歴リセット」**を押すと「すべての訪問履歴を今すぐリセットします。よろしいですか？」と確かめてから、**待たずに履歴をまとめて消します**（対象インスタンスに滞在している間は、いまの滞在の行だけ残します。回数は減りません）。各行にはIDのほか、`00:35 - 00:36 (9分前) 1回目 24人` のように**時刻（入室 - 退出）**・**退出してからの分数**・回数・**退出時の人数**と、ワールド名・種類・Group ID（名前を付けたグループは名前）を表示します。`(9分前)` は退出時刻と今の時刻（時:分）の差で、毎分進みます。まだそのインスタンスにいる行は、退出側と分数を空けて `10:16 -` のように出します。人数は回数の後ろに `12人` と出すもので、**そのインスタンスを離れた時点でいた人数（自分を含む）**です。滞在中ずっと在室者を追いかけているので、VRChatを終了・クラッシュしたときの人数も残ります。まだ滞在している行は空欄になります。長いワールド名やGroup IDは末尾を切らず、右端へ向けて薄くしています。7行＋8行目の半分が見えるので、続きがあることが分かります。右端の細い溝の中のつまみが、いま履歴のどのあたりを見ているかを示します。見出しの左には「訪問履歴 (全8件 00:14~)」として、保持している件数と、いちばん古い行へ入った時刻を出します。**IDの左には、その訪問にどれだけ滞在したかを示す細い縦棒**を出します。長いほど長く滞在した訪問で、**履歴を消すのと同じ60分で最大の長さ**になります。数分の滞在どうしも見分けられるよう、長さは滞在時間の**平方根**で伸ばしています（1分に満たない訪問は小さな丸になります）。いま滞在しているインスタンスの行は、棒ではなく従来どおり ▶ が出ます。
- **履歴の自動リセットを無効にすると（「一般設定」の「履歴の自動リセットを有効にする」をオフ）、手で「履歴リセット」を押すまで履歴を残します。** アプリや PC を再起動しても、VRChat が古いログを消したあとでも消えません（行は `history.json` に保存し、起動したときに戻します）。ただし**最新の500件・入室から30日以内まで**で、それを超えた古い行から消えます（自動リセットが有効のときも同じ上限です）。上限で消えても「直前のリセットを戻す」の対象にはならず、残っている行のインスタンスの目印も外しません。無効にしている間は、見出しの左は件数を出さず `訪問履歴 (2026-09-27 16:24~)` のようにいちばん古い行の日時だけを出し、回数（`n回目`）は VRChat の起動ごとに1から数えます。
- 対象の3種類以外のインスタンスへ**一瞬でも移ってから対象へ戻った**ときは（滞在の長さは問いません）、
  その前後の行の間に `∧ 対象外のインスタンスへ移動 ∨` の帯を入れます。
  対象外へ移ったままVRChatを終了し、次の起動で直接対象へ入った場合も同じです。帯の高さは行の1/3で、背景は行よりわずかに明るく、
  上下は**端まで伸ばした細い線**で挟みます（**現在滞在しているインスタンスの行の上の線も端まで**伸びます。ふつうの行の区切りは今までどおり左右の余白のぶんだけ短いままです）。
  一覧は対象のインスタンスだけを入室の時刻順に詰めて並べるので、帯がないと対象外へ寄り道した区間が「前の行の続き」に見えてしまうためです。
- **VRChatがクラッシュした（正常終了の記録を残さずに終わった）**あと、
  **履歴が消える前（60分以内）にVRChatを立ち上げ直して対象インスタンスへ戻る**と、
  その前後の行の間に `∧ VRChatクライアントがクラッシュしました ∨` の帯を、対象外への移動の帯と同じ見た目で入れます。
  **この文字だけは赤**にして、異常な終わり方だったことが一目で分かるようにしています。
  対象外への移動の帯と重なるときは、`∧ VRChatクライアントがクラッシュしました・対象外のインスタンスへ移動 ∨` と
  1行にまとめます。クラッシュした行の退出時刻には、VRChatのプロセスが消えた時刻
  （このアプリが動いていなかった場合はログファイルの最終更新時刻）が入ります。
- **Windowsが終わるときは状態を保存してから終わり**、設定などのファイルは書いている途中で電源が落ちても壊れないように保存します。
- 訪問情報は **ローカルのログだけ** から取得します。VRChat API等へは通信しません。
  クラッシュの判定に使うのはVRChatのプロセスの**存否と開始・終了時刻だけ**で、
  プロセスのメモリやウィンドウの内容は読みません。
- **行に目印（付箋のような印）を付けられます。** 右手で行を指すと**その行がわずかに白くなり**、そのままトリガーを引くと
  ハート・チェック・注意の3つの選択肢と「ブラウザで開く」が出ます。目印を選ぶと、その行のインスタンス番号の後ろにその印が付きます。
  印は1回の訪問ではなく**そのインスタンスに付く**ので、同じインスタンスの行はすべて同じ印になり、
  あとで同じインスタンスへ戻ったときの行にも引き継がれます。**いま付いている印をもう一度選ぶと外れます**。
  選択肢の外でトリガーを引くと、何も変えずに閉じます。
  設定「トリガーで操作メニューを表示」をオフにすると、行を指しても白くならず、トリガーを引いてもこのメニューは出ません（見出しの「延長」「リセット」は押せます）。
  付けた目印は**アプリを終了しても残り**（`marks.json`）、**付けてから次のログリセット（履歴がまとめて消えるとき）で一緒に消えます**。
- **行から、そのインスタンスのページを開けます。** 目印のポップアップ（ウィンドウでは行の右クリック、または「選んだ行」のボタン）の「ブラウザで開く」を選ぶと、
  vrchat.com のそのインスタンスのページ（`https://vrchat.com/home/launch?worldId=…&instanceId=…`。共有リンクと同じ形）を既定のブラウザで開きます。
  VRChat には何も起きないので、いま滞在しているインスタンスでも押せます（ログに書かれていた場所から作るだけで、APIは使いません）。
  設定の「インスタンス操作の挙動」を「VRChatクライアントを再起動してjoin」にすると、ボタンは**「ここへ戻る」**になり、`vrchat://launch?ref=vrchat.com&id=…` を VRChat へ渡します。
  **VRChat はいまのクライアントを閉じて起動し直すので、FBT のキャリブレーションなどはやり直しになります**（そのため既定はブラウザです）。
  「ここへ戻る」は、いま滞在しているインスタンスの行では「滞在中」と出て押せません。どちらも、入れるかどうか（満員・グループの条件など）はVRChat次第です。
- **撮った写真を、その訪問のサムネイルとして見られます。** ログの `[VRC Camera] Took screenshot to: …` を拾い、対象インスタンスに滞在している間に撮った写真を
  その訪問へ紐付けます。手首のパネルでは1段目の右端にカメラの印と枚数が出ます。ウィンドウの「選んだ行」には写真の小さなサムネイルが並び、
  **押すとその写真を既定のアプリで開きます**（設定の「写真を開くアプリ」で、選んだアプリにも変えられます）。「フォルダーを開く」もあります。
  サムネイルは `%LocalAppData%\VRCInstanceWristory\thumbnails` に作り、**ログリセットでその訪問が消えると一緒に消します**（写真そのものは複写も削除もしません）。
- **一緒にいた人の名前を、ウィンドウの「選んだ行」に出します。** 人数と同じくログの `OnPlayerJoined` / `OnPlayerLeft` から数え、自分は含めません。
  こちらより先に出た人は控えめな色になります。手首のパネルには出しません。
- **グループに名前を付けられます。** ウィンドウの「選んだ行」の「名前を付ける」で打ち込むと（または `settings.json` の `groupNames`）、
  行の3段目に Group ID の代わりにその名前を出します（`Group Public · まったり会`）。設定で、名前の横に Group ID も並べられます。
  VRChat APIを使わないので、名前は自動では付きません。
- **右手首にも付けられます。** 設定の「パネルを付ける手首」で右手首を選ぶと、その場でパネルが右手首へ移り、指す・スクロール・掴む・押すは左手になります。
  右手首の配置は左手首とは別に保存し、まだ合わせていなければ左手首の配置を左右反転したものから始めます。
  このREADMEの「左手」「右手」は、既定（左手首）のときの呼び方です。
- **SteamVRと一緒に、またはWindowsのログオン時に、自動で起動できます**（ウィンドウの「記録と起動」。どちらも既定では無効です）。
  - 「SteamVRと一緒に起動する」は、SteamVRの「起動時に開始するオーバーレイ」へこのアプリを登録します（SteamVRにつながっている間だけ切り替えられます）。
    SteamVRから起動したときは、ウィンドウをタスクトレイに入れて始め、SteamVRの終了と一緒に終わります。
  - 「Windowsのログオン時に起動する」は、スタートアップ（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`）へ `--minimized` 付きの1行を書きます。
    ウィンドウをタスクトレイに入れて始めます。
    SteamVRが起動するのを待って自分からつなぎます。
- **どこから起動してもコンソール（ターミナル）のウィンドウは開きません。** 出力は `%LocalAppData%\VRCInstanceWristory\app.log` へ書き、ターミナルから起動したときはそのターミナルに出します（終わりを待つには PowerShell で `| Out-Host` を付けます）。**ファイルへ残すときは PowerShell では `>` / `*>` ではなく `| Out-File <パス>` を使います**（`>` では PowerShell が出力をつながずに起動するので、ファイルは空のままです）。出力は UTF-8 なので、先に `[Console]::OutputEncoding = [Text.Encoding]::UTF8` を実行しておかないと日本語が化けます。
- **このアプリを起動しただけでは SteamVR を起動させません。** SteamVR が動いていなければウィンドウだけで動き、SteamVR が起動したら自分からつなぎます。
- **外部のアプリから訪問履歴をリセットできます。** ウィンドウの「一般設定」の「外部連携」にあるコマンド（`echo reset>\\.\pipe\VRCInstanceWristory`）を「コピー」し、OyasumiVR のコマンドの実行機能（睡眠モードが有効になったとき）に貼り付けておくと、睡眠モードに入ったときに確認なしで履歴がリセットされます。「外部からの履歴リセットコマンドを受け付ける」をオフにすると受け付けません（既定はオン）。同じPCの同じユーザーからしか届きません。
- **旧名（InstanceIDLogger）から引き継ぎます。** 実行ファイルは `VRCInstanceWristory.exe` です。初めて起動したとき、`%LocalAppData%\InstanceIDLogger` の履歴・目印・設定を `%LocalAppData%\VRCInstanceWristory` へ移し、
  「Windowsのログオン時に起動する」「SteamVRと一緒に起動する」の登録も新しい名前で登録し直します（旧版が起動中のときは、終了してから起動してください）。
  外部からの履歴リセットのコマンドは `echo reset>\\.\pipe\VRCInstanceWristory` に変わったので、OyasumiVR などに書いたものは「コピー」し直してください。
- **新しい版に、ボタン1つで更新できます**（インストーラーで入れた版だけ）。GitHub の Releases に新しい版が出ると、ウィンドウの左下の段の右端に「アプリを更新」、手首のパネルの下部と SteamVR のダッシュボードに「新バージョンが公開されています」と出し、「アプリを更新」を押して「はい」を選ぶと、ダウンロードしてから一度終了し、新しい版で起動し直します。「一般設定」の一番下の「アップデート」には、現在のバージョン・「アップデートを自動確認する」（既定はオン。起動の30秒後と12時間ごと）・「今すぐ確認」・「更新して再起動」があります。勝手に更新・再起動はしません。
- **二重には起動しません。** 起動中にもう一度起動すると、1つ目のウィンドウが（タスクトレイに入っていても）手前に出ます。
- 右手で指した位置に、小さな輪のカーソル（直径約5mm）が出ます（ビームの線は描きません）。当たっている間、右スティックの上下でスクロールし、**右手グリップを握るとパネルを掴んで動かせます**（離すと配置を保存。設定の「手首パネルの移動」をオフにすると掴めません）。見出しのボタンは**指している間だけ色が変わり**、トリガーで押せます。
- **パネルの絵はちらつかずに入れ替わります。** SteamVRへは絵を送り付けるのではなく、こちらがGPU上に持つテクスチャを
  結び付けて中身だけを書き換えます（`SetOverlayTexture`）。従来の `SetOverlayRaw` は渡すたびに絵が入れ直されるため、
  そのたびに1回ちらついていました。
- **履歴が消える前に、VR内で知らせられます**（ウィンドウの「VRオーバーレイ設定」の「リセット予告アイコンを表示する」。既定はオフ）。残り時間が表示タイミング（既定は3分前）を切ると、VRChatのマイクのアイコンの横（既定は左下）に、↻の輪の中にこのアプリのアイコンと同じ3本の線が入った黄色のアイコンが出て、2秒間隔で点滅（既定は5回）して消えます（手首のパネルを出していなくても出ます）。表示位置（8方向）・大きさ・不透明度・点滅回数・表示タイミングはウィンドウの「VRオーバーレイ設定」の「履歴自動リセットの予告通知」で変えられます。アイコンがマイクのアイコンとずれるときは、「マイクアイコン位置（横・縦・奥行き）」で合わせます（予告通知の設定を変えている間は、VR 内にアイコンが5秒間出たままになるので、SteamVR のダッシュボードから見ながら合わせられます）。滞在中でカウントダウンが止まっているとき・履歴の自動リセットを無効にしているとき・履歴が空のときは出ません。「延長」で表示タイミングより上へ戻すと、次に切ったときにもう一度出ます。
  **VRChat の AFK の間（または SteamVR のダッシュボードを開いている間）に見逃したら、戻ってきたときにまだリセットされていなければもう一度出します**（「AFKから復帰時に再表示する」・既定はオン）。
- **滞在中もカウントダウンを数えられます**（「一般設定」の「滞在中はカウントダウンを停止する」をオフにする。既定はオン＝滞在中は止める）。オフにすると、記録するインスタンスへ入った時刻から数え、滞在が「リセットまでの時間」を超えると、いまいるインスタンスの行だけを残して前の行を消し、そこから数え直します。
- **AFK の間はカウントダウンを止められます**（「一般設定」の「AFK中はカウントダウンを停止する」・既定はオフ）。戻ると、止めた時点の残りから数えます。
  AFK は VRChat の OSC（OSCQuery）で受け取るので、**VRChat 側で OSC を有効にしておく必要があります**（アクションメニューの Options → OSC → Enabled）。ほかの OSC アプリと取り合わないよう、UDP 9001 ではなく OSCQuery で知らせた受け口へ送ってもらいます。
- **VRChat側の入力は遮断しません**（スクロールと同時にVRChatの操作も起こります）。

| 項目 | 内容 |

| OS | Windows 11 x64 |
| ランタイム | 不要（配る実行ファイルに .NET 10 のランタイムと System.Drawing.Common を同梱） |

## ビルド

```powershell
git clone <このリポジトリ>
cd VRCInstanceWristory
pwsh scripts\publish.ps1              # 自動検証 → publish → dist の実行ファイルで描画を確認
```

`scripts\publish.ps1` は次を順に行います。手で実行する場合も順序は同じです。

```powershell
dotnet test
dotnet publish src\VRCInstanceWristory -c Release -o dist\VRCInstanceWristory
dist\VRCInstanceWristory\VRCInstanceWristory.exe --render-sample <確認用のpng>
```

> **コードを変えたら毎回ここまで実行してください。**
> アプリは `dist\VRCInstanceWristory` から起動するので、`dotnet build` や `dotnet test` が通っても
> `dist` を更新しなければ実機の動作は変わりません。publish の前にアプリを終了しておいてください
> （起動中はファイルを掴んでいて上書きに失敗します）。

`dist\VRCInstanceWristory` に実行フォルダーができます。中身は次のとおりです。

```
VRCInstanceWristory.exe         本体
openvr_api.dll                  OpenVR SDK v2.15.6（win64）
*.dll（200あまり）               .NET のランタイムと、描画・更新に使う部品（同梱）
Resources\actions.json          SteamVR Input の action manifest
Resources\bindings\*.json       機器別の既定binding
Resources\vrcinstancewristory.vrmanifest  SteamVRへアプリを識別させるmanifest
THIRD-PARTY-NOTICES.md          同梱物の権利表示
licenses\                       OpenVR SDK・Velopack・.NET のライセンス全文
```

この dist はインストーラーで入れた版ではないので、「アップデート」は使えません（ボタンはグレーアウトします）。

## インストーラーと公開

インストーラー・アンインストーラー・自動更新には [Velopack](https://velopack.io/) を使います。

- **公開するとき：** `Directory.Build.props` の `<Version>` を上げてコミットし、同じ版のタグ（例 `v0.2.0`）を push します。
  GitHub Actions（`.github\workflows\release.yml`）が自動検証を通したうえでインストーラーを作り、Releases へ公開します。
  公開した版を、インストールしたアプリが自動更新で見つけます。
- **手元でインストーラーを試すとき：** `pwsh scripts\package.ps1` で `artifacts\releases` にインストーラーができます
  （`VRCInstanceWristoryApp-win-Setup.exe`。開くと、この PC に実際にインストールされます）。
- インストール先は `%LocalAppData%\VRCInstanceWristoryApp`、設定と訪問履歴は `%LocalAppData%\VRCInstanceWristory` で、わざと別にしています
  （Velopack はインストールし直す・アンインストールするときにインストール先をまるごと消すため）。


主なオプション: `--log-directory <path>`（ログフォルダーの上書き）、`--settings <path>`（設定ファイルの場所）、
`--verbose`（詳細な診断）、`--render-sample` と併用する `--scroll <px>` / `--mark-popup`（行を指して目印を選ぶ状態を描く）/ `--reset-confirm`（見出しの「リセット」の確認を描く）/ `--vr-error`（`--window` と併用。SteamVR へつなげない状態の段を描く）/
`--window`（デスクトップのウィンドウ全体を描く。右側のタブは `--tab details|panel|startup`）/ `--dashboard`（SteamVRのダッシュボードの設定の画面とアイコンを描く）、
`--from-steamvr` はSteamVRが起動するときに付けるもので、SteamVRの終了と一緒に終わります。一覧は `--help` に出ます。

- 終了は Ctrl+C か、デスクトップのウィンドウを閉じるか、タスクトレイの右クリックの「VRC Instance Wristory を終了」です。
  自動起動は、ウィンドウの「記録と起動」で「SteamVRと一緒に起動する」「Windowsのログオン時に起動する」を入れたときだけ登録します（既定では登録しません）。
- 起動したときに SteamVR が動いていなければ、SteamVR を起動させずに待ち、SteamVR が起動したら自分からつなぎます（どの起動のしかたでも同じ。`--no-window` のときは Ctrl+C で終了します）。
  このアプリから SteamVR を起動させることはありません。つなげなかったときはPC側の出力に原因を出し、VR内には何も表示しません。
  デスクトップのウィンドウがあれば、SteamVRを終了してもウィンドウだけで動き続けます（`--no-window` のときは一緒に終了します）。
- 二重起動はできません（同じ保存先へ複数プロセスが書き込まないようにするため）。2つ目を起動すると、1つ目のウィンドウを手前に出して終わります。

### 最初にやること（実機の確認手順）

1. SteamVRとコントローラーを接続した状態で `VRCInstanceWristory.exe` を起動し、VRChat でワールドへ入ります。
2. メインメニューの ワールド / Live Now / ソーシャル / VRChat Plus のいずれかを開くと、訪問履歴が左手首に出ます。
   - 左手首の甲側に出ているか、7行＋半行を一覧できるか、IDと右3段が読めるか
   - 右手で指すとカーソルが出るか、右スティック上下でスクロールするか
   - 正面から30度以上ずらすと消えるか、B / Y の短押しで閉じるか
   - 行を指すとその行がわずかに白くなるか、トリガーで目印の選択肢が出て、選ぶとIDの後ろに印が付くか

   を確認します。うまく出ないときは、デスクトップのウィンドウの左下の状態の段に理由が出ます。
   右手首に付けて試すときは、ウィンドウの「VRオーバーレイ設定」でパネル位置を右手首にします。
3. 位置・角度が合わない場合は、パネルを掴んで置き直します（下記）。幅はウィンドウの「パネルの幅」で変えます。
   設定ファイルを直接編集する必要はありません。

### 位置合わせ

**通常動作中にいつでも調整できます。** パネルを右手で指してカーソルを出し、その状態で**右手グリップ**を握ると
パネルを掴んで動かせます。左手首の甲へ置いて離すと、その位置・角度が設定へ保存されます
（右手首に付けているときは左手で指して掴み、右手首用の項目 `rightTranslationMeters` / `rightRotationEulerDegrees` へ保存します）。
掴んでいる間は視線角度による非表示とスクロールを止めるので、動かしている最中に消えることはありません。

- 保存先は設定ファイル（`%LocalAppData%\VRCInstanceWristory\settings.json`）で、角度は度数で書き込まれます。
- 置き直した位置と角度は、ウィンドウの「手首パネルの位置をデフォルトに戻す」で既定へ戻せます。
- 掴み操作は `/actions/main/in/grab`（既定では右手グリップ。右手首に付けているときは左手グリップ）に割り当てています。
- VRChat の操作でグリップを使うときに誤って動かしてしまう場合は、ウィンドウで「手首パネルの移動を有効にする」を切ります。

### SteamVRのbindingについて

`Resources/bindings` に Oculus Touch / Index / Vive / WMR / PICO 向けの既定bindingを同梱しています。
SteamVRが報告する `controller_type` が合わない場合、スクロールのアクションが割り当てられません。そのときは
SteamVRの「コントローラー」→「バインディングを編集」から `VRCInstanceWristory` を選び、
`/actions/main/in/scroll`（vector2）を右スティックへ、`/actions/main/in/grab`（boolean）を右手グリップへ、
`/actions/main/in/close_panel`（boolean）を B / Y ボタンへ、`/actions/main/in/click`（boolean）を右手トリガーへ、
`/actions/main/in/right_aim` を右手の `tip` ポーズへ割り当ててください。
B / Y のない機器（Vive・WMR）では、代わりにメニューボタンを既定で割り当てています。
右手首に付けたときに使う左手の側（`scroll` / `grab` / `click` を左手のスティック・グリップ・トリガーへ、`/actions/main/in/left_aim` を左手の `tip` ポーズへ）も
同梱の割り当てに入っています。SteamVRでこのアプリの割り当てを自分で作り直している場合は、右手首にする前に左手の側も割り当ててください。
バインディング画面にアプリを出すため、起動時に `vrcinstancewristory.vrmanifest` を一時登録します。
「SteamVRと一緒に起動する」を入れたときだけ、SteamVRを終了しても残る登録にします。

パネルは付けた手（既定は左手）の追跡が有効なときだけ表示します。追跡が一瞬切れても500msは残し、指す手のレイが一瞬外れても200msはカーソルとスクロールを続けます（点滅防止）。

### パネルが出ない・消えるとき

デスクトップのウィンドウの左下の状態の段に、手首のパネルを隠している理由が出ます。
`--verbose` を付けて起動すると、隠した理由が変わるたびに、次の名前でログへも出ます。

| 理由 | 意味 |
| --- | --- |
| `ContentNotReady` | VRChat未実行・パネルを閉じている（B/Y・退出・まだ開いていない）・履歴が空 |
| `WristTrackingLost` | パネルを付けた手（既定は左手）の追跡が500ms以上途切れた |
| `ControllerMissing` | パネルを付けた手のコントローラーが見つからない（電源が入っていないなど） |
| `ViewAngle` | パネル正面から30度以上ずれた向きから見ている（0.15秒かけて薄くなりきった） |
| `TextureNotReady` | テクスチャをまだ一度も転送できていない |

B / Y ボタンを短く押しても（0.1秒以内に離す。長押しでは閉じません）閉じない場合は、
SteamVRのバインディングで `/actions/main/in/close_panel` が割り当てられていません。
（メインメニューも一緒に閉じたときは、ログの記録で少し遅れて閉じます。`--verbose` の記録の
「B / Y の短押しを受け取りました。」「メインメニューを閉じたログ（…）で、パネルを閉じました。」でどちらで閉じたかが分かります。）
同じく「延長」「リセット」や目印の選択肢がトリガーで押せない場合は、`/actions/main/in/click`
（右手トリガー）が割り当てられていません。

パネルはオーバーレイ1枚で、見出しも行もつまみも目印のポップアップも同じ絵の中にあります。
見た目が変わったフレームだけ組み立て直して、D3D11のテクスチャとして渡します（渡すたびにちらつく `SetOverlayRaw` は使いません）。
行の文字はスクロールでは描き直さず、行だけを描いた下絵から見えている窓を写しています。

## 設定

`%LocalAppData%\VRCInstanceWristory\settings.json`（存在しなければ既定値で動作）。
例は [settings.example.json](settings.example.json) にあります。ファイルを直接書き換えたときはアプリを再起動してください
（デスクトップのウィンドウで変えられる項目は、ウィンドウから変えればその場で反映します）。

パネルを掴んで置き直したときに書き戻されるのは `translationMeters` / `rotationEulerDegrees` / `rotationQuaternion` だけ
（右手首に付けているときは `rightTranslationMeters` / `rightRotationEulerDegrees` だけ）、
デスクトップのウィンドウで変えたときは、変えた項目だけを書き戻します。
他の項目と、書き加えたコメント代わりのキーはそのまま残ります。

**この設定ファイルに書いた値は既定値より優先されます。** 見た目の設定を変えたのに反映されないときは、この表の既定値ではなく
`settings.json` の記述を確認してください。

| 項目 | 既定 | 説明 |
| --- | --- | --- |
| `logDirectory` | 現ユーザーの LocalLow/VRChat/VRChat | ログフォルダーの上書き |
| `wristSide` | `left` | パネルを付ける手首。`right` で右手首に付け、操作は左手になる |
| `translationMeters` | `[-0.1942504, -0.024928987, 0.08906134]` | 左コントローラー基準の相対位置（m）。既定は開発者が実機で置いた配置。パネルを掴んで置いて決める |
| `rotationEulerDegrees` | `[-48.22, -170.77, -98.8]` | 相対回転の度数 `[pitch, yaw, roll]`。pitch は手前へ倒す量（マイナスで甲側）。既定は位置と同じく実機で置いた配置 |
| `rotationQuaternion` | （既定なし） | 上級者向け。書くと `rotationEulerDegrees` より優先される |
| `rightTranslationMeters` / `rightRotationEulerDegrees` | （既定なし） | 右手首に付けたときの右コントローラー基準の配置。書いていなければ左手首の配置を左右反転したもの |
| `overlayWidthMeters` | `0.14` | パネルの物理幅 |
| `backgroundOpacity` | `0.9` | 背景の**不透明度**（文字には適用しない。0.5〜1.0）。1.0 で完全に不透明、0.9 なら透明度10%にあたる |

| `scrollDeadzone` / `scrollRowsPerSecond` | `0.20` / `6.5` | スクロールのデッドゾーンと最大速度 |
| `cursorSizeMeters` | `0.006` | 右手で指した位置に出るカーソルの大きさ（m）。輪の直径はこの9割 |
| `viewAngleLimitDegrees` | `30` | パネル正面からこの角度以上ずれたら隠す（上下左右それぞれで判定） |

| `autoResetEnabled` | `true` | 履歴の自動リセットを使うか。`false` なら手で「リセット」するまで履歴を残す（`history.json` に保存し、再起動しても消えない。最新の500件・30日以内まで） |
| `vrOverlayEnabled` | `true` | VR オーバーレイ機能（手首のパネル）を使うか |
| `resetWarningEnabled` | `false` | 履歴の自動リセットの前に予告のアイコンを出すか |

## 回数と再起動

- 回数は `n回目` として、その訪問時点の値を各行に残します。後の訪問で前の行は書き換えません。
- 履歴の自動リセットが有効なときは、**自動リセットが入ったときに1から数え直します**。VRChat を起動し直しても、次の自動リセットまでは回数を引き継ぎます（前回の終了から何分空いたかは見ません）。「直前のリセットを戻す」で自動リセットを戻すと、回数もその前の続きに戻ります。手で押す「履歴リセット」と、上限（500件・30日）で古い行が消えたときは数え直しません。
- 履歴の自動リセットを無効にしているときは、**VRChat を起動するたびに1から数えます**（切り替えは次の VRChat の起動から効きます）。
- 回数は `%LocalAppData%\VRCInstanceWristory\counter-state.json` に保存します（ログの複写はしません）。
  「延長」を押した時刻と、履歴を消した区切り（「リセット」で消したときも）も同じファイルに残すので、再起動しても延長は失われず、消えた行も戻りません。
- 目印は `marks.json` に残し、付けてから次のログリセットで消えます。
- 一緒にいた人と写真は、ふだんは保存せず起動のたびにログから組み立て直します（写真のサムネイルだけは `thumbnails` フォルダーに置き、ログリセットで消します）。
  履歴の自動リセットを無効にしているときは、行ごと（一緒にいた人・写真・回数を含めて）`history.json` に保存し、ログの消えた訪問もそこから戻します。
